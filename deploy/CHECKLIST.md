## Opcional: Agent Engine

`deploy/deploy_agent_engine.sh` publica só o agente (`agent/cabe_no_bolso/`) na Agent Platform com `adk deploy agent_engine` (flags conferidas no `--help` do ADK 2.10.0). Não é o caminho da demo e não substitui o Cloud Run; serve para mostrar o agente na console ou como último recurso. Não executar antes do passo 11.

## Se algo falhar

| Sintoma | Causa provável | Ação |
|---|---|---|
| `gcloud builds submit` nega permissão | conta errada (configuração `default`) ou Cloud Build sem acesso ao repositório `agentes` | `export CLOUDSDK_ACTIVE_CONFIG_NAME=mana-gsoares`; conferir `gcloud config list` |
| `/api/saude` responde `modo: sem_llm` com o modelo configurado | SA de runtime sem `roles/aiplatform.user`, ou modelo fora de `global` | passo 3; conferir `GOOGLE_CLOUD_LOCATION=global` nas env do serviço (`gcloud run services describe ... --format=yaml \| grep -A2 GOOGLE_CLOUD_LOCATION`) |
| 404 do modelo nos logs | `gemini-3.8-flash` só responde em `global` (us-central1 dá 404) | idem; reserva `MODELO=gemini-2.5-flash` |
| 429 na banca | rate limit por IP (todos no mesmo Wi-Fi) | já em 120/min; se precisar, `RATE_LIMIT_POR_MINUTO=300 ./deploy/deploy.sh` antes de 10h45 |
| dados indisponíveis | `DADOS=bigquery` sem papel de BigQuery na SA | voltar para `DADOS=csv` (padrão) |
| sessão expirada no meio da demo | redeploy depois de 10h45 ou TTL de 2 h | não redeployar; botão "Reiniciar" na demo |
